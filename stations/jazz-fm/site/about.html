About

An unofficial, non-commercial archive of what Jazz FM has played, built for curiosity and personal research.

What this is

It lists the tracks in Jazz FM's public play history, the same list the "recently played" playlist page shows when you press "View more": the time, the artist and the title. There is no audio, no artwork and no programme descriptions. It is not made, endorsed or checked by Jazz FM or its owner. This site does not host or stream any music. To help you hear a track, each one has plain links (YT, SP, SC, BC) that open a search for it on YouTube, Spotify, SoundCloud and Bandcamp. Nothing from those sites is loaded or embedded here.

How it is made

  • Once a week, a scheduled job asks the JSON service behind the playlist page (listenapi.planetradio.co.uk, the one the "View more" button uses) for the plays since its last run. It does not load or scrape the web page.
  • It asks for 48 plays at a time and pauses a quarter of a second between requests: about 40 small replies, around 100 KB, once a week. It stops as soon as it reaches plays it already has.
  • It identifies itself by name (RadioArchivesBot) with a link to its code, and does not pretend to be a browser.
  • That service's robots.txt asks automated programs to stay out. This archive does not follow it, on purpose: the file is there to keep search engines from indexing raw data, the list is free, public and unauthenticated, no login or paywall is bypassed, and the load is tiny. The full reasoning is in docs/JAZZ-FM.md. If the station objects, collection stops (see Removal requests).
  • The first week of data (6 to 13 November 2026) was collected by hand from the public playlist pages and typed in by screenshot, so a few names may contain mistakes and a few short stretches are missing.
  • The same small program that builds the 6 Music archive builds this site, so the pages and charts match.

What the data can and cannot tell you

  • The play history does not say which show was on. The show shown for each play is worked out from Jazz FM's usual weekly timetable, so it can be wrong when the schedule changes, for a special programme or for a guest presenter.
  • There are no per-episode records. Each show slot on a day is treated as one episode.
  • The archive starts on 6 November 2026 (the first week is hand-collected). Later weeks come from the station's own history service. A gap can appear if a weekly run is missed for more than about a week.
  • There is no genre, country or album information, so the genre and country charts that the 6 Music site shows are not available here.
  • A track is the same track if its artist and title match after ignoring case, accents and suffixes like "(Remastered)". Different versions of a song can be counted together.

Privacy

This website sets no cookies, runs no analytics, shows no adverts and loads nothing from other sites. Searches and filters happen in your browser.

Removal requests

If Jazz FM, an artist or a rights holder asks for something to be changed or removed, it will be, promptly. The place to ask is an issue on the source code page.
