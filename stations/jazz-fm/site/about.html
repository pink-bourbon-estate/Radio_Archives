About

An unofficial, non-commercial archive of what Jazz FM has played, built for curiosity and personal research.

What this is

It lists the tracks shown on the public "recently played" playlist page for Jazz FM: the time, the artist and the title. There is no audio, no artwork and no programme descriptions. It is not made, endorsed or checked by Jazz FM or its owner. This site does not host or stream any music. To help you hear a track, each one has plain links (YT, SP, SC, BC) that open a search for it on YouTube, Spotify, SoundCloud and Bandcamp. Nothing from those sites is loaded or embedded here.

How it is made

  • A scheduled job reads the public playlist page about every 15 minutes. The page only shows the latest few tracks, so this is how the history builds up.
  • Before each visit it checks the site's robots.txt and stops if the page is not allowed. It identifies itself by name with a link to its code, and waits between requests.
  • It does not use the station's private app interfaces, and does not pretend to be a browser.
  • The first week of data (6 to 13 November 2026) was collected by hand from the public playlist pages and typed in by screenshot, so a few names may contain mistakes and a few short stretches are missing.
  • The same small program that builds the 6 Music archive builds this site, so the pages and charts match.

What the data can and cannot tell you

  • The playlist page does not say which show was on. The show shown for each play is worked out from Jazz FM's usual weekly timetable, so it can be wrong when the schedule changes, for a special programme or for a guest presenter.
  • There are no per-episode records. Each show slot on a day is treated as one episode.
  • Collection started on 13 November 2026 and the earlier week is hand-collected, so counts are not the station's full output. Gaps appear when a collection run is missed or delayed.
  • There is no genre, country or album information, so the genre and country charts that the 6 Music site shows are not available here.
  • A track is the same track if its artist and title match after ignoring case, accents and suffixes like "(Remastered)". Different versions of a song can be counted together.

Privacy

This website sets no cookies, runs no analytics, shows no adverts and loads nothing from other sites. Searches and filters happen in your browser.

Removal requests

If Jazz FM, an artist or a rights holder asks for something to be changed or removed, it will be, promptly. The place to ask is an issue on the source code page.
